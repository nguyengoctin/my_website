**C# is Microsoft's | modern, | object-oriented language | combining C++ power | with Visual Basic simplicity.**  
*C# là ngôn ngữ | hiện đại, | hướng đối tượng của Microsoft | kết hợp sức mạnh C++ | với sự đơn giản của Visual Basic.*

**Used for Windows apps, | ASP.NET web development, | Unity games, | and Xamarin mobile apps.**  
*Được sử dụng cho ứng dụng Windows, | phát triển web ASP.NET, | game Unity, | và ứng dụng di động Xamarin.*

**Features garbage collection, | type safety, | and strong .NET | ecosystem integration.**  
*Có tính năng thu gom rác, | an toàn kiểu dữ liệu, | và tích hợp hệ sinh thái | .NET mạnh mẽ.*
