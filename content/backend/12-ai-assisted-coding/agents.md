**AI agents are | autonomous programs designed | to help developers**  
*AI agents là | các chương trình tự trị được thiết kế | để giúp các lập trình viên*

**write code more efficiently.**  
*viết code hiệu quả hơn.*

**These agents can automate | repetitive tasks, | suggest code completions,**  
*Các agents này có thể tự động hóa | các tác vụ lặp lại, | gợi ý hoàn thiện code,*

**identify errors, | and even generate | entire code blocks**  
*xác định các lỗi, | và thậm chí tạo ra | toàn bộ các khối code*

**based on natural language | descriptions or existing | code patterns.**  
*dựa trên các mô tả | ngôn ngữ tự nhiên hoặc | các mẫu code hiện có.*

**They leverage machine learning | models to understand | code syntax, semantics,**  
*Chúng tận dụng các mô hình | học máy để hiểu | cú pháp code, ngữ nghĩa,*

**and context, enabling them | to provide intelligent | and relevant assistance**  
*và ngữ cảnh, cho phép chúng | cung cấp sự hỗ trợ | thông minh và phù hợp*

**throughout the software | development lifecycle.**  
*trong suốt vòng đời | phát triển phần mềm.*
