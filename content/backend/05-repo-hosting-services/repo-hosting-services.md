**Repo hosting services | provide storage, management, | and collaboration tools | for version-controlled code repositories.**  
*Các dịch vụ lưu trữ kho mã nguồn | cung cấp lưu trữ, quản lý, | và công cụ cộng tác | cho các kho mã nguồn được kiểm soát phiên bản.*

**Support Git, Mercurial, Subversion | with features like | branching, pull requests, | issue tracking, code review, | and CI/CD integration.**  
*Hỗ trợ Git, Mercurial, Subversion | với các tính năng như | phân nhánh, pull requests, | theo dõi vấn đề, đánh giá mã nguồn, | và tích hợp CI/CD.*

**Popular services: | GitHub, GitLab, Bitbucket.**  
*Các dịch vụ phổ biến: | GitHub, GitLab, Bitbucket.*
