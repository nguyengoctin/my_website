**LXC (Linux Containers) runs | multiple Linux systems virtually | on a single Linux kernel.**  
*LXC (Linux Containers) chạy | nhiều hệ thống Linux ảo | trên một nhân Linux duy nhất.*

**Provides userspace interface | for kernel containment features | with powerful API**  
*Cung cấp giao diện userspace | cho các tính năng chứa của nhân | với API mạnh mẽ*

**and simple tools | for creating and managing | system or application containers.**  
*và các công cụ đơn giản | để tạo và quản lý | các container hệ thống hoặc ứng dụng.*
