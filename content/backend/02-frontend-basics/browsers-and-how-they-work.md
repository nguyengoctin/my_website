**Web browsers interpret | HTML, CSS, | and JavaScript | to render web pages.**  
*Các trình duyệt web thông dịch | HTML, CSS, | và JavaScript | để hiển thị các trang web.*

**Modern browsers use | rendering engines | (Blink, Gecko, WebKit) | and JavaScript engines, | offering features like | tabs, bookmarks, extensions, | and security | through sandboxing | and HTTPS enforcement.**  
*Các trình duyệt hiện đại sử dụng | các công cụ hiển thị | (Blink, Gecko, WebKit) | và các công cụ JavaScript, | cung cấp các tính năng như | tab, dấu trang, tiện ích mở rộng, | và bảo mật | thông qua sandboxing | và thực thi HTTPS.*
