**Cursor is an AI-powered | code editor designed | to enhance developer productivity.**  
*Cursor là một trình soạn thảo code | hỗ trợ bởi AI được thiết kế | để tăng năng suất cho lập trình viên.*

**It leverages large language models | to provide features | such as code generation, | intelligent autocompletion, | and code refactoring suggestions, | all within a familiar | editor environment.**  
*Nó tận dụng các large language models | để cung cấp các tính năng | như tạo code, | tự động hoàn thiện thông minh, | và các gợi ý tái cấu trúc code, | tất cả trong một | môi trường soạn thảo quen thuộc.*

**Cursor aims to streamline | the coding process | and accelerate software development.**  
*Cursor hướng tới việc hợp lý hóa | quy trình lập trình | và tăng tốc phát triển phần mềm.*
